# FlipPrint UI 设计

> 手动双面打印助手的用户界面设计

---

## 设计原则

1. **简单直观** - 用户一看就懂，不需要学习
2. **渐进引导** - 每一步只展示当前需要的信息
3. **明确反馈** - 让用户知道当前在哪一步、该做什么

---

## 页面结构

### 1. 首页 - 拖入 PDF

```
┌─────────────────────────────────────────────┐
│  FlipPrint                                  │
├─────────────────────────────────────────────┤
│                                             │
│              ┌───────────┐                  │
│              │  📄 PDF   │                  │
│              └───────────┘                  │
│                                             │
│         拖拽 PDF 到这里，或点击选择          │
│                                             │
└─────────────────────────────────────────────┘
```

**交互**:
- 拖拽 PDF 文件到窗口
- 点击区域打开文件选择对话框
- 支持 .pdf 文件

**状态**:
- 空状态：显示拖拽提示
- 拖拽悬停：高亮边框，提示"释放以打开"
- 加载中：显示 spinner
- 加载失败：显示错误提示

## 组件设计

### 1. 拖拽区域 (DropZone)

**状态**:
- 空状态：虚线边框 + 上传图标 + 提示文字
- 悬停状态：边框高亮 + 背景色变化
- 拖拽中：边框变为实线 + 提示"释放以打开"
- 加载中：显示 spinner
- 错误状态：红色边框 + 错误信息

### 2. 步骤指示器 (StepIndicator)

**样式**:
```
● ─ ● ─ ○
1   2   3
```
- 已完成：实心圆 + 勾选图标
- 当前：实心圆 + 数字
- 未完成：空心圆 + 数字

### 3. 页面顺序展示 (PageOrder)

**样式**:
```
┌─────────────────┐
│   4 → 2         │
└─────────────────┘
```
- 横向排列
- 用箭头连接
- 大号字体突出显示

### 4. 按钮

**主按钮**:
- 背景色：主题色 (蓝色)
- 文字：白色
- 圆角：8px
- 高度：48px

**次按钮**:
- 背景色：透明
- 边框：1px 灰色
- 文字：深灰色
- 圆角：8px
- 高度：48px

### 5. 单选选项 (RadioOption)

**样式**:
```
○ 单面打印
● 手动双面打印
```
- 选中项：实心圆 + 文字加粗
- 未选中项：空心圆

---

## 响应式设计

### 最小窗口尺寸
- 宽度：400px
- 高度：500px

### 布局适配
- 大屏幕：居中显示，最大宽度 600px
- 小屏幕：占满宽度，保持边距

## 后续扩展

### 打印机 Profile
为不同打印机保存配置：
- 翻转方向（长边/短边）
- 是否旋转 180°
- 出纸面（朝上/朝下）

### 批量打印
支持同时处理多个 PDF 文件

### 历史记录
记录最近打印的文件和设置
