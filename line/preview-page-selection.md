# 预览 + 页面选择功能开发记录

## 功能概述
在分析页面添加 PDF 预览功能，支持选择要打印的具体页面范围。

## 功能设计

```
┌─────────────────────────────────────┐
│  📄 文件名.pdf          已选 5/10 页 │
├─────────────────────────────────────┤
│  [全选] [奇数页] [偶数页] [反选]    │
├─────────────────────────────────────┤
│  ┌────┐ ┌────┐ ┌────┐ ┌────┐      │
│  │ 1  │ │ 2  │ │ 3  │ │ 4  │      │
│  │ ☑️ │ │ ☐  │ │ ☑️ │ │ ☐  │      │
│  └────┘ └────┘ └────┘ └────┘      │
│  (缩略图1) (2) (3) (4) ...        │
├─────────────────────────────────────┤
│         [开始打印已选页面]          │
└─────────────────────────────────────┘
```

## 技术方案

| 模块 | 实现方式 |
|------|---------|
| 缩略图渲染 | PDF.js Canvas（尺寸 150x200） |
| 页面选择 | 多选框 + 状态数组 |
| 懒加载 | 先渲染可见区域，后续滚动加载 |
| 打印选中页 | 生成临时 PDF（只含选中页） |
